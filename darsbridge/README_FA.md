# درس‌گذر | نسخه آزمایشی رایگان

این کد یک مرورگر اندرویدی فارسی برای بازکردن صفحات آموزشی است. حالت مستقیم از اینترنت گوشی و حالت Tor/Orbot از پراکسی SOCKS محلی در آدرس 127.0.0.1:9050 استفاده می‌کند. Orbot جداگانه باید نصب و به شبکه Tor متصل شود. برنامه دامنه سایت‌ها را به .ir تبدیل نمی‌کند؛ تبدیل پسوند به‌تنهایی کمکی به دسترسی نمی‌کند.

امکانات: مرورگر داخلی، وضعیت اتصال، آدرس‌بار، نشانک، سرویس اختیاری مطالعه متن عمومی Jina Reader با تأیید پیش از ارسال URL، ذخیره محدود متن صفحات برای استفاده آفلاین.

## ساخت APK

از بخش Actions در GitHub روی Build DarsBridge APK وارد شوید. خروجی در Artifacts با نام DarsBridge-APK قرار می‌گیرد. فایل داخل ZIP خروجی app-debug.apk است و روی گوشی اندرویدی نصب می‌شود.

## هشدار

کارکرد در ایران هنوز روی شبکه واقعی آزمون نشده است. هنگام قطع کامل همه مسیرهای ارتباطی خارجی هیچ اپلیکیشنی با تغییر پسوند نمی‌تواند اینترنت تازه ایجاد کند. این اپلیکیشن یک مرورگر ناشناس‌ساز حسابرسی‌شده نیست. برای کار حساس Tor Browser رسمی را به کار ببرید. لینک‌های محرمانه را به Reader نفرستید.
