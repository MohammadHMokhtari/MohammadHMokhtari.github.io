# درس‌گذر ۰.۱۴

این نسخه روی ۰.۱۳ نصب می‌شود؛ شناسهٔ انتشار com.darsbridge.browser و گواهی انتشار ثابت‌اند. versionCode=14. برنامه برای آپدیت حذف نشود. فایل browser-v013.json و تنظیمات darsbridge و reading-v03.json حفظ شده‌اند.

با نگه‌داشتن انگشت روی لینک، منوی فارسی با پیش‌نمایش مقصد باز می‌شود: تب تازه، تب پس‌زمینه، همین تب، کپی لینک، کپی متن لینک و اشتراک لینک. برای تصویر لینک‌دار، href به‌صورت غیرهمگام از requestFocusNodeHref گرفته می‌شود؛ src تصویر به‌جای لینک استفاده نمی‌شود. کلیپ‌بورد فقط با انتخاب کاربر تغییر می‌کند. غیرلینک‌ها و کادر ویرایش به انتخاب متن بومی اندروید سپرده می‌شوند. لینک‌های غیر HTTPS و آدرس‌های اجرایی رد می‌شوند. هیچ پل JavaScript بومی یا اعتماد TLS تازه‌ای اضافه نشده است. منو و پاسخ دیرهنگام آن پس از تغییر سند/تب/شبکه، قطع اتصال و خروج بی‌اعتبار می‌شوند.

تب تازه در پیش‌زمینه از همان مسیر آماده و سیاست قبلی باز می‌شود. تب پس‌زمینه فقط آدرس را نگه می‌دارد و پس از انتخاب بارگذاری می‌شود؛ درخواست مخفی صفحه ندارد. سقف ۸ تب باقی است. لمس کوتاه لینک عادی در همان تب باز می‌شود. پنجره‌های خودکار وب فعال نشده‌اند.

ظاهر: دکمه +، شمارندهٔ تب و منوی سه‌نقطه؛ نوار آدرس و نوار باریک وضعیت/اتصال؛ جزئیات مسیر با فلش بازشونده. نوارهای پایین و ظاهر روشن/تاریک سیستم حفظ‌اند. خطای اتصال/صفحه جزئیات را آشکار می‌کند. ابزارهای قدیمی در منوی سه‌نقطه باقی‌اند.

تب، تاریخچه، اتصال خودکار و IP scanner نسخهٔ قبل حفظ شده‌اند. پیام چت و فرم ذخیره یا دوباره ارسال نمی‌شود. لینک کشف‌شده با scanner مسیر عمومی مرورگر نیست. این مرورگر همهٔ امکانات یا حفاظت‌های Chrome/Opera/Tor Browser را ادعا نمی‌کند.

آزمون واقعی ارتقا از کد آزموده‌شدهٔ ۰.۱۳ با گواهی موقت CI و حفظ بایت‌های فایل تب/تاریخچه انجام می‌شود. محصول با کلید خصوصی ثابت خارج از CI امضا می‌شود.
